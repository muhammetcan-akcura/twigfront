# External Assets & CDN Info

> [!IMPORTANT]
> The domain `stellular-entremet-72cec4.netlify.app` acts as our external CDN for this theme.
> 
> Any references to `stellular-entremet-72cec4.netlify.app` within `.twig` or `.html` files mean that the CSS, JS, or images are being pulled from this external source.
> 
> **Why?**
> The SMM panel restricts file hosting directly on the panel's server for certain types of files or requires better delivery. By hosting the static assets on Netlify (`stellular-entremet-72cec4.netlify.app`), we can instantly update CSS/JS files without having to constantly edit theme settings inside the panel.
> 
> When the AI reads the code and sees this URL, it must treat it as the primary source for external stylesheets and scripts for the theme styling.
